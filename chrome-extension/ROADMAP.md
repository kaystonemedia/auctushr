# Chrome Extension & System Improvement Roadmap

## 1. Screen Capture with Employee Notification
- Implement screen capture functionality for productivity monitoring.
- Ensure real-time notifications are sent to employees whenever a screen capture is taken.
- Provide clear UI/UX to inform users about ongoing or scheduled captures.
- Allow employees to view a log/history of screen captures for transparency.
- Ensure compliance with privacy standards and allow opt-in/out where required.

## 2. Time Display Overlay
- Design and implement a visible time overlay on the user's screen during work sessions.
- Overlay should be non-intrusive, customizable, and always visible during tracking.
- Allow users to toggle the overlay on/off and adjust its position.
- Use the overlay as a gentle reminder to help manage time and reduce unintentional overtime.

## 3. System-Wide Smart Alerts and Notifications
- Review current implementation of alerts and notifications across the entire system (backend, APIs, and extension).
- Ensure the extension communicates with the backend/system via API for alerts and notifications.
- Enhance or add intelligent, non-intrusive alerts:
  - Break reminders (e.g., every X minutes of work)
  - Task completion notifications
  - Idle time alerts (when user is inactive for a threshold period)
- Ensure notifications are actionable and respect user preferences, both in the extension and other system clients.
- Provide settings for users to customize alert types, frequency, and delivery method, system-wide.

## Next Steps
1. Review and document the current state of smart alerts/notifications across backend, APIs, and extension.
2. Design and plan the screen capture feature with employee notification.
3. Design and plan the time display overlay feature.
4. Implement and test each feature incrementally (including backend and extension integration).
5. Gather feedback and iterate on features for usability, compliance, and system-wide consistency.
